# Copyleft files the licence scan (license-scan.py) lets through, for every
# vendored workspace it checks: crates/gui_cosmic and the root.
#
# The policy (CONTRIBUTING.md, "Licences of dependencies"): Improv may link
# LGPL code unmodified; any change we make to LGPL code is published
# upstream, under that licence, as a PR against that project. GPL and AGPL
# are forbidden: the scan fails on them and they cannot be listed here. (The
# one GPL file in the graph, libcosmic's src/localize.rs, is replaced
# outright, not listed: vendor-libcosmic.sh, pop-os/libcosmic#1500.) Any
# other copyleft licence needs a separate decision before it is listed.
#
# One line per file: `<crate>@<version>/<path> <SPDX expression>`, the
# expression exactly as the file's header has it, so a relicensed or new
# file, or a version bump, fails until a human re-reads it. A listed file
# that differs from its upstream crate (the checksum cargo vendor recorded)
# fails too, unless the line ends `patched-upstream: <PR URL>`.
#
# Reviewed by: the lead, 2026-11-09; the maintainer approved LGPL
# dependencies under the policy above.
