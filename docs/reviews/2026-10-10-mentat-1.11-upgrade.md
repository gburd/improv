## Reading it

- **Reads and edits are 9–26% faster** on 1.11.1; first-import is ~10%
  slower (more indexes to maintain), re-import 13–15% faster.
- **Higher RSS is mmap, not heap.** 1.11 sets `PRAGMA mmap_size` to 1 GiB by
  default; mapped file pages count toward RSS but are shared, clean and
  reclaimable. With `MENTAT_MMAP_SIZE=0` a 100k `list` is 82 MiB at the same
  speed (1 051 vs 1 021 ms). Set it to 0 on memory-constrained hosts.
- **+29% on disk** comes from two new indexes: `idx_transactions_aevt` (a
  covering history index for as-of/since, 39 MiB at 100k) and schema-driven
  `idx_auto_avet_*` value indexes (`MENTAT_AUTO_INDEX`, default `schema`; e.g.
  11 MiB on `:cell/key`). Improv doesn't use as-of/since today.
- **Behaviour change seen by the test suite:** opening a store now touches the
  file (WAL restart/checkpoint) even for a read, so a file's mtime no longer
  signals "something was written". `scheduler::no_due_measures_is_a_noop` now
  checks the transaction high-water instead.
