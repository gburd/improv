rounds of 100k- and 200k-cell models, on a c7i.8xlarge (Debian 13, release

Database size: 238.3 → 238.8 MB (100k), 478.7 → 478.7 MB (200k).

**Verdict: neutral.** Every step is within ±4.3%, inside the run-to-run
spread of four rounds; memory and file size are unchanged. As Mentat's
CHANGELOG says, 1.12–1.16 changed nothing in the embedded SQLite engine
(1.12 renamed the package to `mentatdb` and published it; later releases are
PostgreSQL- and DuckDB-side). The gain is in the build: the dependency now
comes from crates.io, so cargo-deny needs no `allow-git` source and no
license clarifications, and a fresh clone builds without reaching Codeberg.
